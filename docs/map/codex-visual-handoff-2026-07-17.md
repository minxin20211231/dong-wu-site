- 底圖是一張靜態圖（webp＋png fallback），其上由 HTML/CSS 疊加：16 個站點圈（`<ol>`）、三段 SVG 路線（陸路兩段＋藍色點狀海路）與帆船透明素材層。第 16 站軟裝家電 icon 已合成進 v2 底圖。

## 視覺規格（沿用既有世界觀）

- 材質語言：C4D 感微縮模型、霧面軟膠、圓潤倒角、精緻針織衣物感；禁黏土顆粒、指紋、亮面玩具塑膠。
- 光向：**左上暖色主光**（全部素材同一光向）。
- 色系：暖燕麥、淺奶茶、低飽和草地、焦糖橘路線、深咖細節、鯨金點綴；海面淡奶茶色晨曦感。禁薄荷綠、粉紅、薰衣草紫、霓虹、純黑背景。
- 每站一個主場景物件、比例一致、物件實體支撐（不懸浮）。

- AI 生圖空間紅線（`feedback_ai_image_spec`）：浴室無椅凳布品畫作植栽；衣櫃／櫃體一律開門式鉸鏈、禁滑門；保護工程用淺色夾板＋牛皮紙膠帶、禁綠藍 PP 板；牆面裝飾只能是無字抽象幾何。
